# T0 保全 Linux 构建环境

目标：云电脑重置后能在 15 分钟内恢复构建能力。

做法：
1. 新建分支 grokbot/linux-bootstrap（只含 bootstrap/ 目录，不带仓库其它内容，可用孤儿分支）。
2. bootstrap/ 内容：
   - 路径垫片：去掉 Windows 长路径前缀 `\?\` 的 python 包装器和 sitecustomize（原样复制你现在用的）。
   - 两个桩文件的生成脚本：诊断 DLL 哈希桩（取仓库里已审核的 pin）和 JS worker 全零桩（注明：全零只为让编译通过，真实值只能在 Windows 上生成）。
   - 完整的 Gradle 命令行：-Dorg.gradle.jvmargs=-Xmx6g -Xss16m、--no-daemon --max-workers=1 --no-parallel -Pkotlin.compiler.execution.strategy=in-process，以及要排除的任务（-x prepareNativeDiagnosticShare -x fetchJsWorkerJdk -x prepareJsWorker，测试运行时再加 -x prepareJsWorkerResources）。
   - 安装 JDK 21（Temurin）、Python、git 的命令。
   - README.md：重置后怎么在 15 分钟内恢复，包含如何确认恢复成功（一条最小的 compileKotlin）。
3. 不含任何令牌、密钥或个人信息。推送按 STANDING-ORDERS 第 3 节直接推。

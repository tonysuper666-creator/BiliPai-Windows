# Windows 专用界面

本轮候选版本为 `0.2.427.5`，复用基线为 BiliPai `v0.2.5` 的固定源码。Windows 继续使用原接口、响应模型、登录与账号、取流、评论、弹幕、队列、缓存和下载业务；桌面窗口布局和输入由 Windows 分支维护。

## 界面与设置

本轮将普通视频改为填满剩余窗口空间，默认收起详情，用细进度轨道和紧凑控制栏操作。点击“详情”查看简介与分P、评论或相关推荐；同一个原生播放组件保持挂载。窄窗口下将次要操作收进菜单。

升级后首次默认选择原版液态玻璃，之后保留手动开关。侧栏、播放器控制栏和详情面板复用原版材质函数；背景来自独立的原壁纸层，未配置壁纸时使用原纯色背景。渲染器能力和背景实际绘制就绪共同控制启用，原首页还保留其自身背景就绪检查。不会截取原生视频，也不承诺跨平台逐像素等同。

主导航采用固定侧栏，同一导航栈保留页面状态、ViewModel、生命周期和返回行为。取消手机横向 Pager、共享元素和卡片变形转场。启动直接进入首页，取消首次协议屏、帮助改进和上次崩溃的开屏提示，不自动写入同意或启用诊断。

普通视频页使用 Windows 布局及同一个原生播放器组件。窗口全屏和大小变化保留这一播放承载；页面保留画质、分集、主副字幕、弹幕、UP、收藏、下载与评论入口。历史续播提示调用原业务建议，评论复用原表情和时间规则。隔离主窗口的本地回放与输入检查已通过；各媒体路径及真实账号仍需要分别验收。

设置归为播放与音频、首页与推荐、外观与显示、缓存与备份、隐私与屏蔽、插件与扩展、更新与诊断七组。保留解码、编码、画质、倍速、字幕、弹幕、播完行为、后台播放、评论、音质与输出设备，保留代理、WebDAV、CDN、播放加速和手动诊断。手机旋转、屏幕亮度、触屏手势、折叠屏、权限与生物识别不作为 Windows 设置。源文件仍作为上游参考或业务依赖保存。

升级后的首次启动默认启用最高可用画质；原取流逻辑继续依据视频和账号权限选择。首次初始化采用同一个设置存储的原子写入，之后手动关闭或选择默认画质会保留，重启不会覆盖。

播放器聚焦时使用原键盘控制；评论输入框保留自己的文字与光标操作。界面缩放支持 Ctrl＋加减、Ctrl＋滚轮，Ctrl＋0 回到 125%。本轮实际 Main 检查已验证这些输入，缩放没有重建原生播放器或重置来源。

## NVIDIA 视频增强

设置 → 播放与音频 → NVIDIA 自动增强，与播放器里的同名开关共享配置。首次升级开启，此后保留手动选择。RTX VSR 根据实际画面区域放大；RTX 视频 HDR 只对有效 SDR 输入、已开启的 Windows HDR 显示器及确认的 HDR 输出目标申请。原生 HDR 保留，不叠加 FSR 或 Anime4K。实际显卡、驱动接受和帧输出分别显示，不用一个已保存开关代替运行确认。

## WASAPI 输出

设置 → 播放与音频 → 音频，可以刷新真实设备列表、选择输出并开启 WASAPI 独占。默认共享。配置在下一次打开媒体时应用，不主动重载当前视频，不改变音量、静音、倍速或暂停状态。

视频 / BV 听视频和独立音频播放器分别显示当前状态。保存偏好或“等待下一次播放”不能视为正在独占；实际输出状态必须来自同一媒体与配置的原生成功读回。设备不存在、被占用或格式不支持时展示失败，独占请求不悄悄降为共享或空输出。

暂停可能仍持有独占设备。从一个播放器切到另一个播放器时，设备占用和恢复仍须实际验证，不能把一个播放器的成功推广到全部媒体路径。

状态显示源音频及送往原生 API 的 PCM 采样率、通道和格式。独占不提高源音质；音量、倍速及音频处理仍可能改变 PCM。界面不认证位完美或 TOSLINK 的实际链路格式。

## 已验证与待验证

此前 `.3` 编译、选定 Windows 测试 35/35、随后独立的 HTTP 错误分类测试 6/6 已通过；独立静音原生播放器的共享、独占、恢复共享三例已通过。真实 Main 的本地回放已验证播放、全屏、窗口大小、Ctrl 缩放、播放器快捷键与评论焦点；API 是内存回放，媒体是本地素材，未使用真实账号。线上 B 站播放与 Devialet 光纤听音仍须实际验收。此前 `.4` NVIDIA 编译与 40 项针对测试通过；本机 RTX 5080 的 D3D11VA、VSR 放大、SDR 到 PQ HDR 帧及 HDR 输出目标读回均通过，窗口缩放、切换本地来源和关闭增强检查通过。便携包检查以本轮构建报告为准，历史结果不能替代本轮 `.5`。详见 [README.md](README.md)。

## 上游同步

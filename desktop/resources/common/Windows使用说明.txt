BiliPai Windows 使用说明
Windows 版本：0.2.427.3

启动
双击文件夹内的 BiliPai Windows.exe。保留 app、runtime 等随包文件；无需 Android 模拟器或额外安装 Java。

常用操作
使用左侧导航进入首页、搜索和设置。视频页支持分集、画质、字幕、弹幕、收藏、下载与评论。
默认选择视频与账号支持的最高画质；可在“播放与音频”关闭此选项并选择默认画质，后续重启保留手动选择。
点击“全屏”进入，点击“退出全屏”或按 Esc 返回；F11 切换窗口全屏。
点击播放器使其获得焦点后，空格控制暂停/播放，左右方向键快退/快进。评论输入框获得焦点后，空格和方向键用于编辑文字。
Ctrl＋加减或 Ctrl＋滚轮调整界面大小，Ctrl＋0 恢复 125%；也可在“外观与显示”中调整。
设置按播放与音频、首页与推荐、外观与显示、缓存与备份、隐私与屏蔽、插件与扩展、更新与诊断归类。代理、WebDAV、CDN、播放加速和手动诊断入口保留。

音频设备与独占
进入 设置 → 播放与音频 → 音频，刷新设备列表并选择实际输出设备。
默认共享。启用 WASAPI 独占后，需要下一次打开媒体才应用；保存开关不代表当前已在独占输出。
页面分别显示视频 / BV 听视频与独立音频播放器的输出状态。以实际“已确认 WASAPI 独占输出”为准。
设备被占用或格式不支持时，查看页面错误并在设备可用后重新打开媒体；程序不会为了独占自动解除静音、改变音量或改为共享假装成功。
暂停的播放器可能仍占用独占设备。独占不会提升视频源音质，也不等同于位完美或光纤格式认证。

账号与播放问题
使用自己的 B 站账号扫码登录。HTTP 412 等请求错误可能影响访客播放；保留页面错误文字并反馈，账号 Cookie 不必提供。
遇到问题时说明当前 Windows 版本、视频 BV 号、操作步骤和可见错误。新桌面布局与各媒体路径仍在逐项验证。

更新与文件保留
本机历史、收藏与界面设置保存在 LocalAppData 中，不必复制到程序目录。程序文件夹可以整体备份；部署时保留上一文件夹和未知附加文件，不自动清理个人文件。
当前源码、测试或开关可见不代表全部功能验收完成；具体交付以本轮实际 EXE 测试结果为准。

# Original independent Bangumi browsing pages integrated

The complete original catalog, season detail and review bodies now mount at their typed Root entries. The original Timeline compatibility component is compiled; the catalog timeline continues through the existing original Hub, since the pinned original defines no separate Timeline NavKey. Season, episode, media and review parameters are preserved. Selecting another season replaces the actual current detail top through the existing route admission and native beforeCommit, preserving the original navigation behavior.

The pages borrow the existing Root Hub repository, DesktopRepository owned raw service, CSRF/session authority and ordinary video progress view. Each actual entry has its own original VM and child scope. Request returns, reducers, follow/review mutations and callbacks retain caller cancellation, account epoch, entry retention and current-page checks. No additional client, persistent Store, native player or resource authority was introduced.

Four exact code/build hunks were rebased onto the already integrated Search revision. The semantic registry delta was independently shown equal to all five frozen registry hunks by unique source identity and every field. The preparation orders new rows differently; rebasing retains the current list order and every existing Search feature. Eight identities and four feature unions are added, with no new dependency or resource. Only the two whitelisted new canonical files were copied. Normal whole-product classes and test-source compilation passed without product overrides; the preparation separately passed 34 original VM/protocol assertions.

The original Bangumi Player is unfinished and its existing typed fallback remains. These browsing pages do not constitute full PGC playback parity. A subsequent actual Root window test on the Search snapshot found a missing existing image-share binding before comment owner creation. That Root assembly repair is being handled separately; normal compilation is not runnable desktop acceptance. Real account/API behavior, the complete Root window, native PGC playback and the new EXE remain unaccepted. Frozen proof, source backups, rebased changes, actual compile log and native producer graph are pinned in artifact-index.json. Compiled fixture binaries and generated trees are not installed as product sources.
